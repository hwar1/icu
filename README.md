# معًا لتوفير سيارة إسعاف لمدينة الظاهرية

موقع حملة تبرعات لعرض وإدارة وجمع التبرعات لشراء سيارة إسعاف، بواجهة عربية كاملة (RTL) بتصميم كحلي ذهبي مبسّط، والتحديث يحدث فوريًا بين جميع الأجهزة دون إعادة تحميل.

## التشغيل

1. تثبيت الحزم:
   ```
   npm install
   ```
2. تشغيل الخادم:
   ```
   npm start
   ```
3. فتح المتصفح على:
   - الشاشة العامة (لا تحتاج دخول): `http://localhost:3000/`
   - لوحة الإدارة: `http://localhost:3000/admin`
   - الإحصائيات: `http://localhost:3000/stats`

الخادم يستمع على `0.0.0.0`، أي أن كل الأجهزة على نفس الشبكة يمكنها فتح الشاشة العامة عبر عنوان الجهاز المحلي، مثال: `http://192.168.x.x:3000/`

## الدخول

- اسم المستخدم: `admin`
- كلمة المرور الأولية: `admin`

**مهم:** قبل نشر الموقع أو استخدامه الحقيقي، غيّر كلمة المرور فورًا من لوحة الإدارة (قسم «تغيير كلمة المرور»). سيظهر تنبيه دائم في اللوحة حتى تغييرها.

## الصفحات

| الصفحة | العنوان | الحماية |
| ------ | ------- | ------- |
| الشاشة العامة | عدّاد ضخم متحرك، نسبة التقدم، شرائح العملات، نافذة احتفال عند كل تبرع | عامة |
| الإدارة | إضافة ومراجعة وتعديل وحذف العمليات + إعدادات الحملة (الهدف، العملة، التواريخ) + تغيير كلمة المرور | تسجيل دخول |
| الإحصائيات | بطاقات KPI، تحليل بالساعة/اليوم/الأسبوع، رسم تطور الحملة، فلترة فترة | تسجيل دخول |

## العملات

- الهدف يُحتسب من **عملة الهدف** المحددة في الإعدادات (افتراضيًا شيكل `ILS`).
- بقية العملات تُعرض في شرائح منفصلة **ولا تُجمع** مع بعضها، ولا تدخل في نسبة التقدم.
- كل رسم بياني في الإحصائيات يعرض عملة واحدة فقط (يختارها المستخدم).

## البيانات

- قاعدة بيانات SQLite في الملف `data/donations.db` (تُنشأ تلقائيًا، مفصولة عن git).
- القاعدة تبدأ **فارغة** — لا توجد أي تبرعات تجريبية.
- كل عملية تُحفظ بمبلغها وعملتها وملاحظة اختيارية وتوقيتها ومن أضافها.

## هيكل المشروع

```
server/
  index.js   الخادم: الواجهات، SSE، حماية الصفحات والواجهات
  db.js      قاعدة البيانات والإحصائيات
  auth.js    كلمة المرور (scrypt) والجلسات
public/
  index.html / admin.html / stats.html / login.html
  css/style.css
  js/        shared.js (أدوات مشتركة) + index/admin/stats
  assets/    صورة الإسعاف
test.js      اختبارات آلية (حماية، عمليات، SSE، إحصائيات، كلمة المرور)
```

## الاختبار

```
node test.js
```

يجري الاختبار الآلي ويترك القاعدة فارغة ويستعيد كلمة المرور الافتراضية `admin` وتنبيه التغيير.

## الإعدادات الافتراضية

- الهدف: `100000` شيكل — يُعدَّل من لوحة الإدارة (قسم إعدادات الحملة).
- البداية والنهاية: تُضبطان على اليوم الحالي تلقائيًا عند أول تشغيل (حملة ليوم واحد).
- صورة الحملة: `public/assets/ambulance.jpg`.

## خارطة طريق مستقبلية

- إضافة نموذج تبرع مباشر من الشاشة العامة مع تحقق.
- تصدير الإحصائيات وإشعارات صوتية عند التبرع.
