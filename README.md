# معًا لتوفير سيارة إسعاف لمدينة الظاهرية

موقع حملة تبرعات لعرض وإدارة وجمع التبرعات لشراء سيارة إسعاف، بواجهة عربية كاملة (RTL) بتصميم كحلي ذهبي مبسّط، والتحديث يحدث فوريًا بين جميع الأجهزة دون إعادة تحميل.

## التشغيل محليًا

1. ثبّت الحزم:
   ```
   npm install
   ```
2. عرّف رابط قاعدة بيانات PostgreSQL في المتغير `DATABASE_URL` (مثال):
   ```
   set DATABASE_URL=postgresql://user:pass@localhost:5432/icu
   ```
3. شغّل الخادم:
   ```
   npm start
   ```
4. افتح المتصفح على:
   - الشاشة العامة (لا تحتاج دخول): `http://localhost:3000/`
   - لوحة الإدارة: `http://localhost:3000/admin`
   - الإحصائيات: `http://localhost:3000/stats`

الخادم يستمع على `0.0.0.0`، أي أن كل الأجهزة على نفس الشبكة يمكنها فتح الشاشة العامة عبر عنوان الجهاز المحلي، مثال: `http://192.168.x.x:3000/`

## النشر المجاني على Render (بدون الحاجة لجهازك)

المشروع مُعدّ للنشر المباشر من مستودع GitHub عبر ملف `render.yaml`، مع قاعدة PostgreSQL مجانية تحفظ كل التبرعات:

1. أنشئ حسابًا مجانيًا على [render.com](https://render.com) واربطه بحساب GitHub.
2. من لوحة Render اختر **New → Blueprint**، ثم اختر المستودع `hwar1/icu`.
3. سيتعرف Render تلقائيًا على `render.yaml` فينشئ خدمة الويب + قاعدة PostgreSQL ويربط `DATABASE_URL` آليًا.
4. انتظر انتهاء البناء، وستحصل على رابط دائم بصيغة `https://icu-campaign.onrender.com`.

ملاحظات:
- خطة Render المجانية تُنيم الخدمة بعد ~15 دقيقة بلا زيارات، ويستغرق إيقاظها ~30–60 ثانية عند أول طلب.
- البيانات تُحفظ في PostgreSQL وتبقى حتى بعد إعادة تشغيل الخدمة.

## الدخول

- اسم المستخدم: `admin`
- كلمة المرور الأولية: `admin`

**مهم:** قبل نشر الموقع أو استخدامه الحقيقي، غيّر كلمة المرور فورًا من لوحة الإدارة (قسم «تغيير كلمة المرور»). سيظهر تنبيه دائم في اللوحة حتى تغييرها.

## الصفحات

| الصفحة | العنوان | الحماية |
| ------ | ------- | ------- |
| الشاشة العامة | عدّاد ضخم متحرك، شرائح العملات، نافذة احتفال عند كل تبرع | عامة |
| الإدارة | إضافة ومراجعة وتعديل وحذف العمليات + إعدادات الحملة (الهدف، العملة، التواريخ) + تغيير كلمة المرور | تسجيل دخول |
| الإحصائيات | بطاقات KPI، تحليل بالساعة/اليوم/الأسبوع، رسم تطور الحملة، فلترة فترة | تسجيل دخول |

## العملات

- العداد الكبير في الشاشة العامة يعرض إجمالي **العملة الأساسية** المحددة في الإعدادات (افتراضيًا شيكل `ILS`)، ويمكن تغييرها من لوحة الإدارة.
- بقية العملات تُعرض في شرائح منفصلة **ولا تُجمع** مع بعضها.
- كل رسم بياني في الإحصائيات يعرض عملة واحدة فقط (يختارها المستخدم).

## البيانات

- قاعدة بيانات **PostgreSQL** تُعرّف عبر متغير البيئة `DATABASE_URL`.
- الجداول تُنشأ تلقائيًا عند الإقلاع، والقاعدة تبدأ **فارغة** — لا توجد أي تبرعات تجريبية.
- كل عملية تُحفظ بمبلغها وعملتها وملاحظة اختيارية وتوقيتها ومن أضافها.
- للاختبارات الآلية تُستخدم قاعدة PostgreSQL وهمية في الذاكرة (`pg-mem`) فلا حاجة لقاعدة حقيقية.

## هيكل المشروع

```
server/
  index.js   الخادم: الواجهات، SSE، حماية الصفحات والواجهات
  db.js      PostgreSQL: التخزين والإحصائيات (async)
  auth.js    كلمة المرور (scrypt) والجلسات
public/
  index.html / admin.html / stats.html / login.html
  css/style.css
  js/        shared.js (أدوات مشتركة) + index/admin/stats
  assets/    صورة الإسعاف
render.yaml  إعداد النشر المجاني على Render (خدمة + قاعدة PostgreSQL)
test.js      اختبارات آلية (حماية، عمليات، SSE، إحصائيات، كلمة المرور)
```

## الاختبار

```
node test.js
```

يجري الاختبار الآلي ويترك القاعدة فارغة ويستعيد كلمة المرور الافتراضية `admin` وتنبيه التغيير.

## الإعدادات الافتراضية

- العملة الأساسية للعرض: `ILS` (شيكل) — تُعدَّل من لوحة الإدارة.
- البداية والنهاية: تُضبطان على اليوم الحالي تلقائيًا عند أول تشغيل (حملة ليوم واحد).
- صورة الحملة: `public/assets/ambulance.jpg`.

## خارطة طريق مستقبلية

- إضافة نموذج تبرع مباشر من الشاشة العامة مع تحقق.
- تصدير الإحصائيات وإشعارات صوتية عند التبرع.
